# PetShop FIAP - Checkpoint 5

Sistema web para um PetShop desenvolvido com **React + Vite + Tailwind CSS**.

## Estrutura do Projeto

```
src/
├── components/
│   ├── Navbar.jsx
│   ├── Footer.jsx
│   └── Card.jsx
├── pages/
│   ├── Home.jsx
│   └── Produtos.jsx
├── App.jsx          # Rotas configuradas com react-router-dom
├── main.jsx
└── index.css        # Tailwind CSS
```

## Tecnologias

- React 19
- Vite
- Tailwind CSS
- React Router DOM

## Como executar

```bash
npm install
npm run dev
```

## Entrega

- Projeto em repositório público de uma organização no GitHub
- Commits semânticos (mínimo 3 por integrante por tarefa)
- Branches: main e dev
- Arquivo `integrantes.txt` na raiz com RMs, nomes e link do repositório
